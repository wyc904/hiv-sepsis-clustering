# 代码总索引

共 **57** 个 R 脚本，按“分析阶段 → 具体用途 → 迭代版本”三级分类。
所有脚本均已通过 R 4.4.0 `parse()` 语法检查。

类型说明：

| 类型 | 含义 |
|---|---|
| 主线 | 当前分析流程使用的脚本 |
| 迭代 | 同一分析的不同版本 / 探索性草稿，保留以备追溯 |
| 工具 | 数据清洗、格式转换、部署等辅助脚本 |
| 依赖 | 需先运行上游脚本、复用其内存对象，不能单独运行 |

> 读取 / 输出由脚本中的字面量自动提取；通过变量拼接的路径不在表中。
