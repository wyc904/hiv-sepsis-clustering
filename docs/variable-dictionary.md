## 2. 结局与分组变量

| 变量 | 含义 | 使用位置 |
|---|---|---|
| `cluster` | GMM 聚类标签（1 / 2） | 聚类主脚本、统计与绘图 |
| `cluster0` | 二分类聚类标签（0 / 1） | 校准脚本 |
| `死亡终` | 死亡结局（0 / 1） | `4-log.R`、ROC 分析 |
| `day28_outcome` | 28 天结局 | 饼图、KM |
| `hoslos` | 住院时长 | KM |
| `new_score` | 风险评分 | H–L 校准检验 |
| `p` / `p_recal` | 预测概率 / 重校准后概率 | 校准曲线 |

## 4. 命名注意事项

- 原始数据中同一个概念可能存在多个列名（`CD48` / `CD4`、`HIVRNA8` / `VL38`），
  不同脚本按当时的数据表字段使用，跨脚本衔接时需核对；
- `02_统计与校准/02_校准评价/4-校准图形绘制.R` 将 `cluster0` 转为 `死亡终_num`，
  字段含义需结合原始数据确认；
- `02_统计与校准/04_迭代版本/4-log.R` 的 ROC 分析使用了 `死亡终`，而模型结局为
  `cluster`，两者不一致；正式结果请使用
  `03_预测建模/01_主模型/2-逻辑回归系数生成.R`。
